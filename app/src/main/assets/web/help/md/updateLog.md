**2026/06/21**
- 修复主题设置右上角日间/夜间切换图标颜色不跟随当前主题的问题，切换后图标会重新按顶栏文字色着色
- 备份过程新增阶段进度条，显示导出数据库、整理资源、压缩、写入本地和上传 WebDav 等当前步骤，减少大备份时误以为卡死的情况
- 恢复过程新增阶段进度条，覆盖读取备份、恢复数据库、封面图集、阅读记录、配置、资源缓存和应用恢复结果等步骤

- 优化备份选择器，封面图集默认不再自动勾选，避免大量封面图片随普通备份一起打包导致备份耗时过长或低内存设备崩溃
- 封面图集分组菜单新增“上传 WebDav”，支持将单个封面图集分组导出为 zip 后独立上传，并增加空分组拦截、重复上传拦截、临时文件清理和上传失败提示

**2026/06/20**
- 修复备份/恢复在低内存或异常备份包场景下的稳定性问题：章节目录和阅读记录大表改为分页导出，Web 备份同步采用分页导出，ZIP 创建失败和备份目录异常会明确报错，恢复先解析成功再覆盖本地数据，避免坏包误清空本地配置
- 修复最近新增代码中的若干稳定性问题：优化本地 TTS 段落朗读进度回调，避免暂停、停止或切换章节后仍残留等待任务
- 修复书架批量更新目录队列的并发访问问题，降低多线程刷新时队列状态错乱的概率
- 修复懒加载章节续排在章节取消后仍可能继续写入旧排版状态的问题，并补齐懒加载段评气泡图片解析
- 修复选择性恢复阅读记录时备份数据异常可能误清空本地阅读记录的问题，增强阅读记录日期解析容错
- 修复顶栏包和气泡包导入时同名包可能覆盖本地已有配置的问题，导入时自动生成唯一目录
- 优化封面图集顺序模式缓存，限制缓存条目并在删除、重随机和恢复时清理旧状态，避免异常缓存导致封面索引越界
- 优化气泡管理列表 SVG 预览，改为后台渲染并避免列表复用时串图
- 优化图片裁剪保存流程，减少多余 Bitmap 复制并确保临时缩放图在异常场景下释放
- 清理段评气泡相关无用常量和未使用方法，减少维护冗余
- 补齐主题管理中的封面设置能力，新增高清封面加载开关、日间/夜间封面图集选择和随机/顺序/混合封面模式，并修复封面图集入口文案
- 主题设置新增气泡管理入口，补齐右上角帮助说明、原版内置段评气泡预设和阅读页段评气泡渲染链路，支持本地段评气泡 SVG 模板、颜色、大小配置与 zip 导入，并优化页面主题色与夜间模式适配
- 优化书架刷新时同一书源的目录更新并发控制，由单任务串行调整为最多两个任务并行，减少刷新期间打开同源书籍时的等待时间，同时保留书源限流保护
- 修复本地 TTS 长章节朗读时一次性提交整章内容可能导致系统 TTS 音频回调占用过高、在 256MB 堆内存设备上内存溢出崩溃的问题，改为按段落提交并忽略过期回调
- 进一步降低朗读服务内存峰值，小堆设备不再预排版缓存下一章，通知封面限制解码尺寸，并避免朗读段落列表构建时复制整章文本
- 修复部分系统 TTS 注册进度回调后仍持续通过 Binder 回传音频块，低内存设备可能在 ITextToSpeechCallback 中崩溃的问题，本地 TTS 改为不注册系统回调并轮询播放状态推进段落
